# Fragile Parcel Service Guide
Standard Economy accepts G4-packed fragile glass but provides only NOK 2,500 declared-value cover and no mandatory signature. NordGround Secure accepts G4-packed fragile glass, supports Bergen, provides signature delivery, and offers cover up to NOK 50,000.
