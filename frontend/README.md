# Frontend target

One screen, two columns:

- Traditional RAG
- Context Compiler

Context Compiler renders an event timeline with statuses such as:

- SEARCHING
- DOCUMENT_FOUND
- VERSION_CONFLICT
- TEMPORAL_CHECK
- OUTDATED_SOURCE
- FOLLOWING_REFERENCE
- EVIDENCE_ADDED
- VERIFYING
- SUPPORTED
- UNKNOWN

Primary demo interaction: ask the same security question twice with different dates and show that the answer flips because different policy versions were valid.
